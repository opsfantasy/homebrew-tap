# mortalxu98/homebrew-tap

Homebrew casks for [mortalxu98](https://github.com/mortalxu98)'s apps.

```bash
brew install --cask mortalxu98/tap/email-vault
```

| Cask | App |
|---|---|
| `email-vault` | [Email Vault](https://github.com/mortalxu98/email-vault) — offline, encrypted password vault organized by email |

Casks are updated automatically when a new release is published.
