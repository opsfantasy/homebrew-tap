# opsfantasy/homebrew-tap

Homebrew casks for [opsfantasy](https://github.com/opsfantasy)'s apps.

```bash
brew tap opsfantasy/tap
brew trust opsfantasy/tap          # Homebrew 7+ asks you to trust third-party taps
brew install --cask email-vault
```

| Cask | App |
|---|---|
| `email-vault` | [Email Vault](https://github.com/opsfantasy/email-vault) — offline, encrypted password vault organized by email |

Casks are updated automatically when a new release is published.
